> ### РЕАКЦИИ АНТИВИРУСОВ
>
> WinDivert иногда определяется антивирусами.  
> Это средство перехвата и фильтрации сетевого трафика, необходимое для работы zapret.
> Его могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит файлы WinDivert к потенциально опасным или хакерским инструментам. В результате файл удаляется и помещается в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы хорошо понимаете, что именно настраиваете, предпочтительнее добавить исключение. При неуверенности рекомендуется отключить обнаружение PUA.

## ⚙️ Использование

1. Активируйте безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS, отличный от "Поставщика по умолчанию".
    * В Firefox откройте настройки "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную введите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокирован.
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Этот вариант рекомендуется пользователям Windows 11.
    * Для роутеров Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/Darkgluapplaud40/zapret-discord-youtube/releases/latest).

3. Откройте свойства скачанного архива и установите флажок "Разблокировать". Пользователи 7-Zip или PeaZip могут пропустить этот шаг.

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите необходимый файл.
    * Для поиска подходящей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Чтобы включить автоматический запуск, выберите **`service.bat`** → `Install Service` → подходящую стратегию.

## ℹ️ Кратко о файлах и командах

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) предназначен для установки автозапуска и выполнения других операций:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск служб (services.msc)</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — изменение режима обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно запустить заново.**  
  Значение в скобках показывает, включён режим или выключен.
  - **`IPSet Filter`** — выбор режима обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Настройка полезна при проверке ресурса, который без zapret работает, а с ним — нет.  
  Текущее состояние отображается в скобках:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP сверяется со списком
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для исправления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ручная проверка наличия обновлений
  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном отказе клиента.
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если этого не произошло, ознакомьтесь с [#522](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues/522).

### Подходящей стратегии нет

- Откройте командную строку с правами администратора.
- По очереди выполните команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - Откройте файл `hosts` в созданном каталоге через текстовый редактор, запущенный от имени администратора.
  - Вставьте скопированный текст в конец `hosts` или замените им ранее добавленные аналогичные записи.
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Результат не гарантирован. Если способ не помог, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Darkgluapplaud40/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вариант, который некоторое время работал, может перестать работать после его обнаружения.
> В репозитории собрано много стратегий. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них, изменив параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте сообщения об ошибках через `service.bat` → `Run Diagnostics`.

- Убедитесь, что нужный адрес присутствует в списках доменов или IP.

- Попробуйте другие стратегии, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация есть в [#765](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Выполните `service.bat` → `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце выберите Y.
- Удалите старую папку zapret.
- Скачайте свежую версию [со страницы релизов](https://github.com/Darkgluapplaud40/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Откройте свойства архива через контекстное меню. Если внизу справа присутствует флажок разблокировки, установите его и нажмите «Применить» → «ОК».
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов.
- По очереди проверяйте разные `general`-скрипты. Если ресурсы не открываются, закройте программу через значок замка на панели задач и запустите следующую стратегию.
- После выбора рабочего варианта установите его в автозапуск: `service.bat` → `Install Service` → нужная стратегия.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Используйте инструкцию из раздела https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide.

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Узнайте имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите службу, подставив имя из первого шага:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если раньше всё работало, переберите остальные стратегии.
- См. также [#251](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8F-использование) настроен.
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её.
- Откройте `service.bat` → `Run Diagnostics` и очистите там кэш Discord.
- Проверьте, заработало ли приложение после очистки.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, её можно использовать.
- Если браузерная версия также недоступна, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/Darkgluapplaud40/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: при `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Лучше определить все IP-адреса, которые использует игра, и внести их в `ipset-all.txt`.

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Нужной проблемы нет в списке

- Создайте обращение [здесь](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Расширить перечень ресурсов для обхода можно с помощью следующих файлов:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть уже указана в `ipset-all.txt`, но конкретный домен фильтровать не следует
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, исключённые из обработки
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
